# Third-party image attributions

This repository bundles 16 small Wikimedia Commons thumbnails for its local demo gallery. The table records the credited creator, license label, linked Commons file page, and local thumbnail filename from `data/demo/assets.json`. The Commons file page is the authoritative source for current license and restriction information; the project rechecks machine-readable metadata when `image-search seed-demo` downloads the gallery. Metadata can change, so verify the source page before reuse.

These images are **not** relicensed under the repository's MIT source-code license. Follow each image's own license, including attribution and ShareAlike conditions where applicable. The source files and thumbnail checksums are recorded in `data/demo/assets.json`.
